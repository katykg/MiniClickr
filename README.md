\# MiniClickr



\*\*Simple, lightweight \& free auto-clicker + macro recorder for Chrome / Chromium.\*\*



Record mouse movements, clicks and scrolls, then replay them at any speed.  

Also includes a fast interval clicker with fixed-position option.

\### Features

\- Record \& Play macros (with speed control and repeat)

\- Interval clicking (custom ms + fixed position)

\- Visual click beacon

\- Global hotkeys:

&#x20; - `Ctrl + Shift + C` → Toggle Interval

&#x20; - `Ctrl + Shift + R` → Toggle Record

&#x20; - `Ctrl + Shift + P` → Toggle Play / Stop

\- Draggable floating panel

\- Works on almost any website

\- Completely free

\### Installation



\*\*Chrome Web Store\*\* (recommended)  

→ \*Link will be added here after approval\*



\*\*Manual / Raspberry Pi / other Chromium browsers\*\*

1\. Download the latest release or clone this repo

2\. Open `chrome://extensions` (or `chromium://extensions`)

3\. Enable \*\*Developer mode\*\*

4\. Click \*\*Load unpacked\*\* and select the extension folder
